# E1.22C — Authoritative static-tier → hook seam GREEN

Date: 2026-09-15
Status: GREEN (source proof)
Scope: PRIME / Hermes prompt-tier observability only

## Proven runtime path

`agent/conversation_loop.py` proves that when prompt caching is enabled Hermes calls `_ensure_cached_system_prompt_static(...)`, reads `agent._cached_system_prompt_static`, and passes that exact value to `build_prompt_cache_plan(..., static_system_prefix=...)`.

Therefore `agent._cached_system_prompt_static` is the authoritative live representation of Hermes' internal `stable` tier for the system prompt. It is not the same concept as `agent.prompt_cache_boundary.find_stable_prefix(...)`, which serves builder-declared skill/webhook/cron message scaffolds.

## Hook gap

The same request path invokes `pre_api_request` with:
- full `system_prompt`
- `request_messages`
- provider/model/request telemetry

but does not currently expose `agent._cached_system_prompt_static` to the hook.

This prevents the RYZ3N Cache Controller from measuring the authoritative Hermes static tier without guessing from the provider-facing request shape.

## Smallest correct intervention

Expose the already-existing `_cached_system_prompt_static` value to the `pre_api_request` observer hook. The RYZ3N Cache Controller may use it transiently to compute only:
- static-tier character count;
- static-tier fingerprint/hash;
- static share of full system prompt;
- non-static remainder size;
- stability continuity across turns/providers.

Raw prompt/static-prefix content must never be persisted, logged, printed, or returned.

## Non-goals

This change must NOT:
- mutate the prompt;
- alter prompt ordering;
- alter routing;
- alter provider selection;
- alter cache behavior;
- alter tools;
- alter ARC identity/governance;
- introduce a parallel prompt framework.

## Acceptance

E1.22C source proof is GREEN when:
1. authoritative static tier is identified as `agent._cached_system_prompt_static`;
2. the live cache-plan call site is proven to consume it;
3. the hook exposure gap is proven;
4. the next intervention is limited to behavior-neutral observability.

All four are satisfied by the live source trace on 2026-09-15.
