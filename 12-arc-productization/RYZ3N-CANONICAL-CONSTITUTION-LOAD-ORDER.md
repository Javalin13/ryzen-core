## Final-state constitutional check

Every material change ends with:

`PASS 1 — Reality`
What actually exists/runs now?

`PASS 2 — Implementation alignment`
Does that reality match Founder intent, the relevant canonical rules, approved architecture, and local scope?

`PASS 3 — Evidence`
Can every material claim be proven?

If a pass fails, READY/COMPLIANT/LIVE may not be declared. Correct or explicitly defer the drift, then rerun all three passes.

## Principle

The constitution is not an inspiration layer. It is the invariant against which the implementation is continuously tested.

`Canon → interpretation → design → implementation → evidence → convergence`

Never invert this into:

`implementation convenience → retroactive canon interpretation`.
