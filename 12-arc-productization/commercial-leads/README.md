## Purpose

This folder records real ARC commercial prospects that are **not yet authorized ARC instances**.

A lead belongs here when there is meaningful sales activity, pricing/scope discussion or follow-up that should remain durable, but the customer has not yet crossed the Founder authorization gate for ARC creation.

This folder is deliberately separate from:

- PRIME `FACTORY.md` — autonomous ARC creation/lifecycle registry;
- PRIME OMEGA registry — ARC population/lifecycle stewardship;
- `founding-pilots/` — Founder-authorized pilot/customer arrangements;
- client ARC repositories — detailed source/runtime state after creation is authorized.

A commercial lead must not receive an ARC ID reservation, OMEGA active registration, FACTORY instance entry, runtime or maturity claim merely because a proposal was sent.
