# Falsification & Inference-to-Evidence for Reliable Excellence

**Status:** Canon-Rooted Reliability Skill Profile — **NO NEW CANONICAL AUTHORITY**  
**Constitution/Canon impact:** none

## Purpose

Falsification & Inference-to-Evidence describes the technique of taking an inference, heuristic hypothesis, diagnosis or architectural belief and identifying the evidence that could efficiently disprove, weaken or sufficiently support it for a decision.

This is not a new verification or scientific Brain. The underlying responsibility already exists in Canon.

## Canonical ownership boundary

Relevant existing owners/mechanisms include:

- **Layer 22 — Emergent Cognition Research & Self-Model Analysis**, explicitly constrained by scientific rigor, **falsifiability**, operational validation and reality grounding, while preserving hypotheses and failed assumptions;
- **Layer 19 — Recursive Adversarial Validation & Failure Simulation**, which challenges dangerous assumptions, hidden fragility and failure scenarios;
- Recursive Verification, which critiques and validates candidate outputs before execution;
- Constitution Compliance / Mission Controller acceptance gates for objective proof;
- OMEGA for operational evidence quality and reliability claims;
- FACTORY for converting recurring falsified assumptions into reusable prevention.

This profile sharpens **test design** inside those responsibilities. It does not own falsifiability or create another evidence authority.

## Core rule

> **When intelligence proposes X, ask not only why X may be right, but what observation would show X is wrong.**

## Reliability role

Useful technique includes translating plausible explanations into testable claims, choosing high-information discriminating tests, searching for disconfirming evidence, separating real tests from convenient proxies, checking evidence independence, isolating assumptions and stopping verification once consequence-appropriate evidence is sufficient.

Reference loop:

`observation → inference/hypothesis → predicted consequences → discriminating test → evidence → falsify/weaken/strengthen → existing Recursive Verification → bounded action → outcome verification`

## Evidence independence

Several pieces of evidence may share the same failure source. Where material, test for shared source dependence, copied/derived evidence, common model/provider or sensor failures, shared configuration assumptions and whether supposedly separate tests actually exercise different failure paths.

## Failure modes

Prevent confirmation-only testing, circular self-validation, many weak proofs replacing one decisive test, correlated evidence mistaken as independent confirmation, proxy metrics treated as outcomes, tests unable to fail by design, acceptance criteria moved after failure and endless verification without evidence gain.

## Verification targets

Possible measures include time-to-disconfirm wrong hypotheses, information gain per diagnostic action, percentage of material hypotheses with falsification criteria, confirmation-bias error rate, correlated-evidence failures detected and false closures prevented.

## OMEGA / FACTORY relationship

OMEGA may reject circular/proxy-only/correlated evidence packages for operational reliability claims. FACTORY may encode recurring decisive tests, negative tests and falsification conditions into production gates.

Scientific/adversarial ownership remains with the relevant canonical layers.

## Governing principle

> **Falsification is already canonical scientific discipline. This profile makes its operational technique sharper; it does not create a second scientific or verification authority.**
