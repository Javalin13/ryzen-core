## Purpose

This document is the **idea backlog** for the `ryzen-core` repository. It is the depository for ideas that:

1. Are *interesting* but do not pass the **Founder Reality Check Protocol** (7-dimension scorecard).
2. Are *out of scope* for the current rebuild phase.
3. Are *blocked* by the 3 open founder decisions (D1, D2, D3).
4. Are *post-rebuild* (R3+, R4+, or post-R4).

The idea backlog is **additive only**: new ideas are appended, never reordered, never removed. A future revision of an idea is added as a new entry with a reference to the prior entry.

## The Format

```
## YYYY-MM-DD — <idea title>

- Status: <parked | deferred | blocked | post-rebuild | declined>
- Parked by: <founder | hermes | co-author>
- Reason: <one-line explanation>
- Founder Reality Check: <scorecard, if executed>
- Reference: <path to related document, when applicable>
- Next action: <when to revisit, or "no next action">
```
